# 회원별 QQQ/SPY 관심 종목 API와 추가 스키마

기준: 2026-11-12 한국 시간. 이번 주 금요일까지 연구 성과를 제외한 회원·채팅·관심 기능을 완성한다는 사용자 결정에 따른 Java 기능 작업이다.

## 시작

- 원격 Java main `0b9e926`; #10~#15는 의존 순서로 열린 초안이다. #15 최종 `5b1ad39`의 원격 게이트 6개 성공. 기존 작업 트리는 덮어쓰지 않고 #15에서 새 작업 트리 분기.
- 현행 Java는 회원과 QQQ/SPY 대화를 소유하며 관심 종목 테이블/API가 없다. Python #11에 별도의 임시 관심 기능이 있으나 운영 데이터 소유자는 Java다. React에는 관심 목록 저장 UI가 아직 없다.
- EC2는 사용자가 확인한 `0b9e926`이며 아직 V1 Flyway/BlueGreen 파일이 없다. 사용자는 IAM 역할과 터미널 접근을 확인했지만 서버 `.env`/TLS/SMTP/DB 상태는 미확인. 이 변경이 곧바로 운영 배포된다는 주장은 하지 않는다.

## 구현

- 회원 JWT로 확인한 서버측 회원 ID에만 묶이는 `GET /api/v1/watchlist`, `PUT /api/v1/watchlist/{symbol}`, `DELETE /api/v1/watchlist/{symbol}`. QQQ/SPY만 허용하고 다른 종목은 명시적으로 거절한다.
- MySQL 추가 V2: `member_watchlist` 신규 테이블과 `(member_id,symbol)` 유일 제약·회원 FK. V1 회원과 채팅 구조를 건드리지 않는다. 기존 V1 앱 이미지와 새 V2 이미지가 같은 DB에 붙을 수 있는지 격리 Blue/Green 인수 시험으로 확인한다.
- 기존 격리 smoke의 최신 스키마 기대값을 V2로 변경. 신버전 HTTP 관심 목록 작성/조회와 단일 스택 컨테이너 재생성 뒤 목록 보존을 검증한다. Blue/Green의 구버전에는 신기능 경로를 호출하지 않는다. 운영 DB 볼륨이나 공개 이미지에는 시험 전용 삭제 명령을 적용하지 않는다.

## 검증과 운영 한계

- 신규 Spring 통합 시험은 익명 조회/수정 거절, 다른 회원 분리, 반복 PUT/DELETE, 미지원 종목 차단을 실제 H2/JPA/Security/MockMvc 경로에서 확인한다. Docker 격리 CI는 실제 MySQL/Flyway V1→V2·기존 회원·채팅 보존 및 구/신 버전 전환을 확인해야 한다.
- 로컬 환경은 Java21은 있지만 Gradle 8.5 다운로드 네트워크 제한·Docker CLI 부재로 Java 전체/JAR/운영 이미지 인수가 불가. 원격 최종 커밋 CI 성공 전에는 구현 완료 판정을 보류한다.
- 반복 PUT은 순차 요청에 멱등이며 동시에 다른 세션에서 같은 회원/종목을 넣는 경합은 DB 유일 제약이 마지막 방어다. 충돌 응답 개선은 별도로 처리한다. 임의 종목 지원, 뉴스/시세/목표주가, React 저장 버튼, 운영 EC2 배포를 이번 Java API 완료에 포함하지 않는다.
- DB 스키마 호환은 추가 테이블과 격리 시험 범위다. 실제 운영 DB가 존재하면 원본 백업/테이블 비교 후만 적용한다. 독립 미래 정답과 모델 성과는 HOLD이며 상품 수요와 별개다.

## 작업량·중간 오류·완료 근거

회원별 API 3개, 영속 엔티티/저장소, 추가 SQL 1개, 합성 통합 시험 1개, 배포 인수 시험의 스키마 확인 수정, 이 기능 리뷰를 포함한다. 초기 명령에서 기존 `java` 작업 트리를 기준으로 V1 경로를 찾았으나 새 `java-watchlist` 작업 트리에서 경로와 대상 커밋을 다시 확인해 수정했다. 최종 원격 커밋의 전체 CI·JAR·Docker·Blue/Green 게이트는 PR 생성 후 결과로 업데이트한다. 기존 비공개 성과 문서 전체 업로드와 비밀값 노출은 하지 않는다.
