# 현재 제품 방향: 공통 API와 관심 종목 AI 기능

기준일: 2026-11-16. 이번 사용자 결정의 기준 문서이며 상세는 [구조 설계](architecture/08-core-api-and-model-extension.md)를 따른다. 과거 방향은 Git 이력으로 보존한다.

- doChallenge는 회원·채팅·관심 종목과 사용자용 API의 중심이다. React는 이 API를 통해 RAG 브리핑과 향후 예측 결과를 조회한다.
- ShockGarph_AI는 공시·뉴스 RAG와 별도 예측 모델 어댑터를 소유한다. 친구의 딥러닝 모델은 명세와 실행 자원이 확인된 후 독립 워커로 연결한다.
- 첫 출시의 브리핑·차트·회원·QQQ/SPY 채팅을 유지한다. 모델 개발·성능 검증을 기존 출시의 선행 조건으로 추가하지 않는다.
- 뉴스 근거의 방향성 해석과 미래 가격·수익률·변동성 예측은 화면·API·평가에서 구분한다. 실전 예측 성능은 독립 미래 정답과 검증 근거가 없으면 HOLD다.
- 이번 변경은 설계 문서다. 작업 큐·모델 API·추론 워커·통합 운영 배포는 아직 구현 완료가 아니다.
- 웹 PR #8의 주간 계획은 기본 일정으로 유지하고, 모델 연동은 명세 수령 뒤 별도 작업으로 잡는다. 기존 문서의 '연구 모델 첫 출시 제외'는 첫 출시 선행 조건에서 제외한다는 뜻으로 유지하며 확장 자체를 금지하지 않는다.
- 저장소 이름 변경·새 유료 서버·GPU 도입·초안 자동 병합·운영 배포는 이번 결정에 포함하지 않는다.
