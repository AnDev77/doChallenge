# 현재 제품 방향: 공통 API와 관심 종목 AI 기능

결정 기준일: 2026-11-17 KST. 구현 상태 갱신: 2026-11-19 KST. 상세는 [구조 설계](architecture/08-core-api-and-model-extension.md)를 따른다. 과거 방향은 Git 이력으로 보존한다.

- doChallenge는 회원·채팅·관심 종목과 사용자용 API의 중심이다. React는 이 API를 통해 RAG 브리핑과 향후 예측 결과를 조회한다.
- doChallenge Java가 공시 수집·검색·LLM 초안·사람 검토·Kafka 작업 처리와 공개 브리핑을 소유한다. ShockGarph_AI Python은 예측·가격 연구를 담당한다. 병합된 Python #18은 Java 구현의 출처·인용·검토 규칙을 참고할 이력이다. 친구의 딥러닝 모델은 명세와 실행 자원이 확인된 후 독립 워커로 연결한다.
- 첫 출시의 브리핑·차트·회원·QQQ/SPY 채팅을 유지한다. 모델 개발·성능 검증을 기존 출시의 선행 조건으로 추가하지 않는다.
- 뉴스 근거의 방향성 해석과 미래 가격·수익률·변동성 예측은 화면·API·평가에서 구분한다. 실전 예측 성능은 독립 미래 정답과 검증 근거가 없으면 HOLD다.
- Java에는 CAMT SEC 공시 수집, 키워드 근거 검색, Spring AI 모델 어댑터를 통한 내부 초안 생성, 초안·인용 저장과 해시 조건부 승인 서비스가 구현되어 있다. 모델은 기본 비활성이고 실제 공급자 호출·품질 평가는 미검증이다. 생성 실행기·인증된 사람 검토 경로·Kafka 소비/영속 작업·Java 승인 결과의 공개 GET 전환·통합 운영 배포는 아직 없다. 현재 공개 GET의 BriefingGateway는 Python 내부 결과를 조회한다.
- 웹의 기존 11/18·11/20 일정은 새로운 Java RAG 완료 일정으로 간주하지 않는다. 모델 연동은 명세 수령 뒤 별도 작업으로 잡는다. 기존 문서의 '연구 모델 첫 출시 제외'는 첫 출시 선행 조건에서 제외한다는 뜻으로 유지하며 확장 자체를 금지하지 않는다.
- 저장소 이름 변경·새 유료 서버·GPU 도입·초안 자동 병합·운영 배포는 이번 결정에 포함하지 않는다.

- Kafka의 첫 운영 적용은 Java의 CAMT 공시 브리핑 초안 생성 작업이다. 사용자 조회 GET은 Java의 검토된 결과만 읽는다. Python #18의 파일 의도와 가짜 Kafka 시험은 구현 이력이며 운영용 DB 아웃박스·실브로커 검증이 아니다.
